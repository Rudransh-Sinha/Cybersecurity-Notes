# Cellular Networks

Mobile phones communicate using **radio waves**.

- Phones connect to nearby **cell towers (antennas)**.
- During a phone call, the signal is forwarded from one tower to another until it reaches the destination.
- Cellular networks are used for:
  - Voice calls
  - SMS (Text Messages)
  - Mobile Internet

### Common Mobile Network Technologies

| Technology | Description |
|------------|-------------|
| GSM | Standard cellular network used worldwide |
| 3G | Faster mobile internet than previous generations |
| 4G / LTE | High-speed mobile data, still widely used |
| 5G | Latest generation offering higher speed and lower latency |

---

# Wi-Fi

Wi-Fi allows devices to connect to a **local network** and access the Internet without cables.

### Wi-Fi Features

- Uses wireless access points (routers).
- Can be private or public.
- Public Wi-Fi is commonly available through hotspots.
- Devices automatically connect to known Wi-Fi networks.

---

# Bluetooth

Bluetooth is a short-range wireless communication technology.

### Uses of Bluetooth

- Wireless headphones
- Speakers
- Keyboard & Mouse
- Car audio systems
- File sharing between devices

### Bluetooth Characteristics

- Low power consumption
- Short communication range
- Multiple devices can connect simultaneously

---

# Bluetooth Pairing

Before two Bluetooth devices communicate, they must be paired.

### Pairing Process

1. Turn Bluetooth ON.
2. Make one device discoverable (visible).
3. Search for nearby devices.
4. Select the device.
5. Confirm the pairing request.
6. Enter PIN if required.

### Information Shared During Discovery

A discoverable Bluetooth device can provide:

- Device Name
- Bluetooth Class
- Supported Services
- Technical Specifications

---

# NFC (Near Field Communication)

NFC enables wireless communication over a **very short distance**.

### Common Uses

- Contactless payments
- Smart cards
- Device pairing
- Data sharing

Range is usually only a few centimeters.

---

# Mobile Device Connectivity

Modern smartphones usually support both:

- Wi-Fi
- Cellular Data

If a trusted Wi-Fi network is available, the phone generally connects to Wi-Fi first. Otherwise, it uses mobile data if enabled.

Popular mobile operating systems include:

- Android
- Apple iOS

---

# Wireless Security Best Practices

When using Wi-Fi, remember these security practices:

- Never send passwords over unencrypted (plain text) connections.
- Use a VPN whenever possible on public Wi-Fi.
- Secure your home Wi-Fi network.
- Use WPA2 or WPA3 encryption.
