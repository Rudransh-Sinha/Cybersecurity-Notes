## Overview

Understanding network media is important because every network communication depends on a reliable transmission medium.

---

# Network Media Types

Network media provides the path that allows data to travel from one device to another.

Modern networks mainly use three types of transmission media:

## Metal Wires (Copper Cables)

Copper cables transmit data using **electrical signals**.

They are commonly used in:

- Ethernet LANs
- Home networks
- Office networks

Advantages:

- Low cost
- Easy to install
- Widely used

---

## Fiber Optic Cable

Fiber optic cables transmit data using **pulses of light** through glass or plastic fibers.

Advantages:

- Very high speed
- Long-distance communication
- Not affected by electrical interference
- Higher reliability

Common uses:

- ISP backbone networks
- Data centers
- Enterprise networks

---

## Wireless Transmission

Wireless networks transmit data using **electromagnetic waves** instead of cables.

Examples:

- Wi-Fi
- Bluetooth
- Cellular Networks

Advantages:

- Mobility
- Flexible installation
- No physical cable required

---

# Factors for Choosing Network Media

Selecting the right network media depends on several factors.

### 1. Distance

How far does the data need to travel?

Long-distance communication often requires fiber optic cables.

---

### 2. Installation Environment

The environment affects the type of cable or wireless technology that should be used.

Examples:

- Home
- Office
- Industrial environment
- Outdoor installation

---

### 3. Speed and Data Requirements

Different applications require different transmission speeds.

High-speed communication may require fiber optic cables instead of copper.

---

### 4. Cost

Budget is also an important factor.

Copper cables are generally less expensive than fiber optic installations.

---

# Common Network Cables

## Twisted Pair Cable

The most commonly used cable in Ethernet networks.

Used in:

- Home LANs
- Office LANs

---

## Coaxial Cable

A copper cable commonly used by:

- Cable TV providers
- Broadband Internet
- Satellite communication systems

---

## Fiber Optic Cable

Uses light instead of electricity.

Benefits:

- Faster transmission
- Longer distances
- Resistant to electromagnetic interference (EMI)

---

# Security Perspective

As a cybersecurity learner, I realized that protecting a network is not only about software and firewalls.

The physical transmission media also plays an important role.

For example:

- Damaged cables can interrupt communication.
- Unauthorized physical access can compromise a network.
- Fiber optic cables are more resistant to electrical interference than copper cables.
- Choosing the right network media improves both performance and reliability.
