# Module 4 - Build a Home Network

## Overview

In this module, I learned how a home network is built and how different networking devices work together. I explored wired and wireless technologies, Wi-Fi standards, router configuration, and best practices for securing a home network.

---

# Home Network Basics

A typical home network connects multiple devices to the internet through a router.

### Common Devices

- Desktop & Laptop
- Smartphones
- Smart TV
- Printer
- Security Cameras
- Smart Home Devices

A home router usually provides:

- Internet access
- LAN connectivity
- Wi-Fi
- DHCP services
- Basic firewall protection

Most home routers support both **wired (Ethernet)** and **wireless (Wi-Fi)** connections.

---

# Network Technologies in the Home

Home networks use both wired and wireless technologies.

## Wired Network

Ethernet is the most common wired networking technology.

### Features

- Fast and stable connection
- Low latency
- Less interference
- Ideal for gaming, servers, and desktops

The most common Ethernet cable used in homes is **Cat5e UTP (supports speed upto 1Gbps)**.

---

## Wireless Network

Wireless networks transmit data using radio waves.

Most Wi-Fi devices operate on:

- **2.4 GHz**
- **5 GHz**

Bluetooth also operates on the **2.4 GHz** frequency but has a much shorter range than Wi-Fi.

---

# Wireless Standards (IEEE 802.11)

Wi-Fi follows the IEEE 802.11 standards.

The Wi-Fi Alliance certifies devices from different manufacturers to ensure compatibility.

### Important Router Settings

## Network Mode

Determines which Wi-Fi standard the router supports.

Examples:

- 802.11b
- 802.11g
- 802.11n
- Mixed Mode

---

## SSID (Network Name)

SSID stands for **Service Set Identifier**.

- It is the name of the Wi-Fi network.
- Devices use the SSID to identify and connect to the correct wireless network.

Example:

```
Home_WiFi
```

---

## Wireless Channel

A wireless channel is the communication path used by Wi-Fi devices.

- Default setting is usually **Auto**.
- Choosing the correct channel can reduce interference.

---

## SSID Broadcast

Controls whether the Wi-Fi name is visible.

Enabled:

- Anyone nearby can see the network.

Disabled:

- Users must manually enter the SSID before connecting.

---

# Setting Up a Home Router

Basic router setup includes:

1. Connect the router to the ISP.
2. Connect a PC using an Ethernet cable.
3. Access the router configuration page.
4. Configure:
   - SSID
   - Wi-Fi Password
   - Security Settings
5. Save and reboot if required.

---

# DHCP

Most home routers automatically assign IP addresses using **DHCP (Dynamic Host Configuration Protocol).**

This means devices receive an IP address automatically without manual configuration.

---

# Router Security Best Practices

While configuring a home router, follow these practices:

- Change the default administrator password.
- Use a strong Wi-Fi password.
- Enable WPA2 or WPA3 encryption.
- Avoid using your personal name or router model as the SSID.
- Disable unnecessary features.
- Create a Guest Network for visitors.
- Use MAC Address Filtering if additional access control is required.
