**Client-Server**

Clients are computer hosts that have software installed that enables the hosts to request and display the information obtained from the server.

Server are the hosts which have software installed that enables them to provide information to the other hosts in the network.

________________________________________________________________
**Types Of Network:-**

P2P :-
- It allows the devices to act both as the sever and the client within the same communications .
- A single computer can run multiple types of server software and same goes with the client software.
ISP :-
- It provides the link between the home network and the internet.
- The primary medium that connects the internet backbone is fiber optic cable . This cable is typically installed underground and also run under the sea.
