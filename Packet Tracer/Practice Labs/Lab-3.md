# Packet Tracer Lab - Configure a Wireless Router and Client

## Lab Information

- **Course:** Cisco Networking Academy - Networking Basics
- **Module:** Build a Home Network
- **Lab:** Configure a Wireless Router and Client
- **Platform:** Cisco Packet Tracer

---

# Objective

In this lab, I configured a home wireless router, connected wired and wireless devices, enabled automatic IP addressing using DHCP, and verified internet connectivity for all devices.

---

# Network Topology

Devices used:

- Home Wireless Router
- Office PC (Wired)
- Laptop (Wireless)
- Bedroom PC
- Internet / External Web Server

---

# Tasks Performed

## 1. Configure the Wireless Router

- Connected the router to the network.
- Accessed the router configuration page.
- Configured the wireless network.
- Saved the router settings.

---

## 2. Connect the Laptop

- Connected the laptop to the Wi-Fi network.
- Verified that the wireless connection was successful.
- Tested internet connectivity by opening the browser.
- Successfully reached the **skillsforall.srv** webpage.

---

## 3. Test the Office PC

- Verified the Office PC had network connectivity.
- Opened the web browser.
- Confirmed internet access by loading **skillsforall.srv**.

---

## 4. Configure the Bedroom PC

- Changed IP configuration to **DHCP**.
- Automatically received an IP address.
- Verified successful internet connectivity using the browser.
